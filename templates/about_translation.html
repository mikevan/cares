How it works

Zero friction. Zero configuration.

Your browser already tells every website what language you prefer. CARES listens — and responds in kind.

Browser detects language

Your browser sends its preferred language with every request. No extra steps needed.

AI translates the page

A purpose-built language model translates the rendered HTML — preserving all formatting, numbers, and links.

Cache serves it instantly

Translations are cached by content. If the page hasn't changed, no API call is made — it's instant.

Smart invalidation

Add a transaction or a member and the page re-translates automatically. Stale translations are never served.

Architecture

Built on specialized language models

CARES doesn't use a general-purpose chatbot for translation. It uses a dedicated small language model (SLM) optimized for translation accuracy and speed — running entirely off-premise on serverless infrastructure.

This means no translation server to maintain, no data leaving a controlled pipeline, and cost that scales to near zero with caching. At chapter scale, a full cache warm-up costs less than a postage stamp.

Future editions will use fine-tuned models trained on nonprofit accounting terminology — so net assets becomes activos netos, not a generic dictionary translation.
